# לאג מזויף (Fake Lag)

אפליקציית ווינדוס שגורמת למצלמה ולמיקרופון בזום/מיט להיראות ולהישמע כאילו האינטרנט קורס.

## איך זה מתחבר
מצלמה אמיתית ← האפליקציה (אפקטים, חלון מוסתר) ← `http://127.0.0.1:5174/obs` ← OBS (מקור דפדפן ← מצלמה וירטואלית) ← זום/מיט

הכתובת עונה רק מהמחשב עצמו: גם החיבור וגם כותרת ה-Host חייבים להיות מקומיים.
מיקרופון אמיתי ← האפליקציה (קיטועים) ← VB-Cable (CABLE Input ← CABLE Output) ← זום/מיט

## הרצה בזמן פיתוח
```
npm install
npm start
```
- `npm run selftest`: עובר על כל המצבים ושומר צילומי מסך ב-`selftest/`. בודק גם את השלט בטלפון.
- `npm run dist`: בונה קובץ התקנה ל-`dist/`. בגלל מגבלת אורך נתיב של NSIS, צריך להריץ מתיקייה עם נתיב קצר.

## קבצים
| קובץ | מה |
|---|---|
| `main.js` | הגדרות, חלונות, קיצורים גלובליים (Ctrl+Alt+Shift+מספר), שרת השלט לטלפון (פורט 5174, עם קוד סודי) |
| `renderer/cam.js` | המצלמה והאפקטים, ניתוק אוטומטי, התחברות מחדש, מסך "מצלמה נכבית" |
| `renderer/lag-worklet.js` | קיטועי הקול, כמו איבוד חבילות ב-VoIP |
| `renderer/control.*` | שלט, הגדרות, עזרה, ואשף בהפעלה הראשונה |
| `renderer/remote.html` | השלט שנפתח בטלפון |
| `renderer/i18n.js` | כל הטקסטים, בעברית ובאנגלית |
