# לאג מזויף · Fake Lag

<img src="docs/logo.png" width="72" align="left">

שאלה קשה בזום? האינטרנט שלך פתאום קורס.
לחיצה אחת, והמצלמה מתחילה לקרטע, מיטשטשת, הקול נקטע, ובסוף אתה "נופל" מהשיחה. עובד בזום ובגוגל מיט.

<br clear="left">

## הורדה
[קובץ ההתקנה לווינדוס](../../releases/latest) · חינם

צריך גם: [OBS Studio](https://obsproject.com) ו-[VB-Cable](https://vb-audio.com/Cable/), שניהם חינם. אשף ההגדרה באפליקציה מלווה אותך.

## איך זה עובד
מצלמה אמיתית ← האפליקציה (אפקטים) ← OBS (מקור דפדפן ← מצלמה וירטואלית) ← זום/מיט
מיקרופון אמיתי ← האפליקציה (קיטועים) ← VB-Cable ← זום/מיט

| קיצור | מה קורה |
|---|---|
| `Ctrl+Alt+Shift+1` | רגיל |
| `Ctrl+Alt+Shift+2` | לאג |
| `Ctrl+Alt+Shift+3` | איכות גרועה |
| `Ctrl+Alt+Shift+4` | קוביות |
| `Ctrl+Alt+Shift+5` | קפיאה |
| `Ctrl+Alt+Shift+6` | מצלמה נכבית |
| `Ctrl+Alt+Shift+0` | ניתוק אוטומטי |
| `Ctrl+Alt+Shift+9` | התחברתי מחדש |

יש גם שלט בטלפון: סורקים QR באותה רשת Wi-Fi.

## פרטיות
הכל רץ על המחשב שלך. שום תמונה או קול לא נשלחים לשום שרת. השלט בטלפון עובד רק ברשת המקומית ועם קוד סודי, והכתובת ל-OBS עונה רק מהמחשב עצמו.
